Premortem Ledger

Paste a plan. A Pollinations model writes how it failed — then extracts the assumptions that killed it, each with an early signal and a cheap test you can actually run this week. You decide which assumptions survive contact with evidence.
BYOP: approve a scoped key on the Pollinations consent screen (5 Pollen, 7 days). One premortem is one chat completion billed to your Pollen.
The failure story is generated; the assumption ledger is parsed from it and checked against the plan text. No generated code runs on this page.

Assumption ledger

Mark each assumption as tested once you have evidence, or killed if the evidence contradicts it. Killed assumptions stay killed.

Generated on request by a language model. The failure story is a hypothesis, not a forecast. An assumption that survives here has only survived your evidence so far.
